# Sprout launch-policy drafts

These files are implementation templates, not legal advice and not approved
policies. Replace every bracketed item, have qualified counsel and a tax
professional review the final text for every launch jurisdiction, publish the
approved HTTPS pages, then record their versions and review details in
**FlexiPOS SaaS Settings**.

The operator dashboard deliberately reports legal and tax review as pending
until those fields are completed. Application code must not mark either review
approved automatically.
